# JSNode

**Version:** 0.0.2  
**Live Demo:** https://your-username.github.io/jsnode/

A Comprehensive Javascript Node Editor that runs entirely in the browser.

## Features

- ✅ Visual node-based JavaScript editor
- ✅ Excel-mimic navigation (top & bottom bars)
- ✅ Adjustable simulation speed
- ✅ Console & Debug drawers
- ✅ Grid snapping & minimap
- ✅ White/Grey/Blue theme

## Deploy to GitHub Pages

1. Fork this repository
2. Go to Settings → Pages
3. Select `main` branch as source
4. Your site will be live at `https://your-username.github.io/jsnode/`

## Local Development

Simply open `index.html` in any modern browser. No build step required!
